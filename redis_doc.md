| key                        | value            |
| :------------------------- | :--------------- |
| blog:posts                 | 全部文章列表     |
| blog:post:[id]             | 文章详情         |
| blog:post:[id]:tags        | 文章标签列表     |
| blog:tags                  | 全部标签列表     |
| blog:tag:[tagname]         | 标签下全部文章   |
| blog:tag:info:id:[tagname] | 通过名字获取 id  |
| blog:tag:info:name:[tagid] | 通过 id 获取名字 |
